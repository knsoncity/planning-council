우리의 AI 회의실

macOS 팀원용 설치본 · 간단 회의 9회 / 전체 회의 61회

GitHub 없이 이 ZIP만 전달하면 됩니다. 각자 Mac에서 실행하며 회의 기록은 자동으로 서로 공유되지 않습니다.

1. 처음 한 번 준비하기

  1. Python 공식 macOS 설치 파일로 Python 3.10 이상을 설치합니다. 이미 있으면 생략합니다.
  2. Codex CLI 공식 설치 안내와 Claude Code 공식 설치 안내에 따라 두 프로그램을 설치합니다. CLI 프로그램은 ZIP에 포함되지 않습니다.
  3. 본인 또는 회사에서 발급한 OpenAI API 키와 Claude API 키를 준비합니다. 회사가 사용하는 경우 관리자에게 개인별 키 발급과 사용 예산을 요청하세요. ChatGPT/Claude 월 구독료와 별도 과금됩니다.

코드의 CLI 옵션은 Codex 0.163.0, Claude Code 2.1.304 설치 환경을 기준으로 확인했습니다. 연결 확인.command가 필요한 옵션의 지원 여부를 검사합니다.

2. 설치하기

  1. ZIP 압축을 풀고 설치.command를 더블클릭합니다.
  2. 사용자 홈/Applications/AI Meeting Room 폴더가 열리면 연결 확인.command를 실행합니다. 이 검사는 설치·옵션만 확인하며 API 결제·잔액·모델 접근까지 보증하지 않습니다.
  3. Claude 초기 설정.command를 실행하고 본인의 Claude API 키를 입력합니다. Claude의 기본 설정과 API 키 인증 확인을 완료한 뒤 /exit로 종료합니다. 다른 구독 계정에 로그인할 필요는 없습니다.

macOS 보안 경고가 나타나면 배포자를 확인한 후 시스템 설정 → 개인정보 보호 및 보안에서 해당 파일의 실행을 허용하세요. 이 ZIP은 Apple 서명·공증된 앱이 아닙니다. 보안 기능 전체를 끄지 마세요. 실행 권한이 풀렸다면 터미널에서 압축을 푼 폴더로 이동해 chmod u+x *.command를 실행합니다.

3. 회의실 열기

  1. 설치된 폴더의 실행.command를 더블클릭합니다.
  2. OpenAI API 키와 Claude API 키를 입력합니다. 입력한 글자는 화면에 표시되지 않습니다.
  3. 브라우저에서 http://127.0.0.1:8876이 열립니다. 첫 시험은 간단 회의로 시작하세요.
  4. 사용을 마치면 실행한 터미널에서 Control+C를 누릅니다. 실행 중인 회의는 중단됩니다.

키는 앱 설정 파일에 저장하지 않습니다. Codex 인증은 이번 실행 전용 임시 폴더에 저장했다가 정상 종료 시 삭제합니다. Claude CLI의 초기 설정은 전용 폴더에 남습니다. 강제 종료·전원 차단 시 임시 파일이 남을 수 있습니다. 계정 인증 파일이나 실행 중 생성된 폴더를 다른 사람에게 전달하지 마세요.

알아둘 점

  • 회의 입력과 토론 내용은 API 키에 해당하는 OpenAI·Anthropic 서비스로 전달됩니다. 회사 자료 사용 범위를 확인하세요.
  • 간단 회의는 9회, 전체 회의는 61회 AI 호출입니다. 호출 수 감소가 일정한 비용 절감을 보장하지 않으며 앱 자체의 금액 상한 기능은 아직 없습니다.
  • 기존 개인 Codex·Claude 설정을 복사하거나 수정하지 않습니다. 배포본에 포함된 범용 planning-council 지침을 사용합니다.
  • 팀원 간 공동 편집·자동 동기화·공용 계정 기능은 없습니다. 필요하면 회의실의 기록 내보내기로 선택한 회의를 공유하세요.
  • API 인증·잔액·모델 권한에 문제가 있으면 회의가 실패로 표시됩니다. 키·결제 설정을 확인하고 미완료 단계 재시도를 사용하세요. Claude가 키 확인을 요구하면 초기 설정을 다시 실행하세요.

업데이트 · 기록 · 삭제

새 ZIP을 받은 뒤 설치.command를 다시 실행하면 프로그램 파일만 갱신합니다. 실행 중인 회의실을 먼저 종료하세요.

회의 기록: ~/Library/Application Support/AI Meeting Room/data
Claude 설정: ~/Library/Application Support/AI Meeting Room/auth/claude

앱만 지우려면 ~/Applications/AI Meeting Room 폴더를 삭제합니다. 기록까지 지우려면 필요한 회의를 내보낸 후 Application Support의 AI Meeting Room 폴더도 삭제합니다. 실행 중에는 삭제하지 마세요.

연결 기준: OpenAI 인증 안내 · Claude 개발자 인증 안내
설치본에는 제작자의 계정 인증정보·실제 회의·회사별 사례가 포함되지 않습니다.
